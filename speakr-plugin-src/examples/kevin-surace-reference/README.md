# Kevin Surace — Reference Example

This folder is a **fully-populated example** of what a client looks like once onboarded.

It is **not loaded by the pipeline at runtime** — it exists so colleagues can see what good looks like:

- Brand context and positioning structure
- Writing guidelines / voice DNA
- SEO guidelines structure
- Two example blog posts in the client's voice
- Brand graphics guidelines

## When to use this

- You're onboarding a new client and want to see a complete example before filling in your own.
- You're writing your first blog post for a new client and want to compare against a strong reference.
- You're customizing the pipeline for your own clients and need a benchmark.

## How to use this

Run `/client-onboarding` to set up your own client. The skill will generate equivalent files in `clients/<your-slug>/` based on the materials you provide.

**Do not copy these files directly into your `clients/` folder** — they contain Kevin Surace's specific voice, brand colors, and SEO strategy.

## Folder contents

- `blog-post-creation/guidelines/` — Kevin's writing voice, SEO strategy, positioning canvas
- `blog-post-creation/examples/` — two example blog posts in his voice
- `blog-graphics/references/` — brand guidelines (colors, typography, layout patterns)
